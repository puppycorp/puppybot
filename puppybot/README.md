# Historical path compatibility

The production implementation is in [`src/`](../src/README.md).
This directory only retains `core`, a compatibility link to the Rust controller
used by independent tests in [`tests/reference/`](../tests/reference/README.md).

The former Rust applications and firmware are available in Git history.
Run `flexscript run puppybot.flex` from the repository root for the current
controller, or see the [main README](../readme.md) for builds and firmware.
