# Diverse-room legacy level convention and pilot catalog

Run `python3 -B -I experiments/diverse-teacher-level-swap-v1/audit.py` from
the repository root. This read-only script compares retained initial robot and
brick positions to each catalog's vertical room boundary and matches each saved
environment to its current catalog bytes. It also prints the proposed 12-case
catalog and file hashes and invokes the old draft's read-only seed preflight.
See diary entry 99 for exact interpretation, split, and the necessary future
registration and training boundaries. No simulator, model, dataset, or report
is modified. The proposal does not authorize collection or training.
