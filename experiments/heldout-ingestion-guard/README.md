# Isolated reserved-scene ingestion guard

`prepare.py NEW_DIRECTORY` copies the preserved handoff-v3 Flex source archive
and builds a baseline and a separate guarded control. It changes neither the
active control source/binary nor the source archive. This is an experimental
CPU-build artifact; it does not enable selection qualification or held-out
evaluation, and no real reserved scenes are generated by it.

For scene-consuming `collect`, `run` and `correct` commands, the guarded
control requires an explicit scene and the environment variables
`PUPPYBOT_RESERVED_MANIFEST` and `PUPPYBOT_RESERVED_MANIFEST_SHA256`. The
manifest must match the supplied SHA-256 and the fixed 160-row virtual-fetch
reservation mapping. The guard requires fitting metadata and rejects an
explicit reserved role, missing or malformed metadata, and a case or
environment whose exact SHA-256 appears in the reservation. Symlinks are
resolved by reading their contents, not trusted by name.

Each scene's case, environment and layout are copied into private memory and
checked before they are written into the run directory; the written copies
are hashed again, and the controller uses the copied layout. Thus changing a
source path or symlink after the snapshot does not change the simulator's
input. The test suite also tampers with a destination between writing and its
hash check and verifies rejection before the fake simulator starts. Failed
runs can leave a new incomplete output directory or partial dataset; retain
and inspect them rather than treating them as completed runs. Temporary scene
and manifest snapshots are released after use; the bounded synthetic memory
test includes a deliberately leaky negative control.

The manifest digest is supplied by the caller, so an external reviewed
launcher must bind it to a pre-registered reservation. This prototype guards
only explicit scene ingestion through `ve_open` in this copied binary. Old
control binaries and other ingestion paths remain unguarded; raw previously
produced datasets and semantically equivalent modified scenes are not
detected by exact hashes. Source files or copied outputs modified after their
checks by a same-user process are not protected against an adversary. No
physical-robot, model-provenance, semantic-independence or held-out
qualification claim follows.

`python3 -I experiments/heldout-ingestion-guard/test.py` builds temporary
native controls and runs CPU-only synthetic reservations and local stub
processes. Local Unix sockets may require the sandbox restriction lifted. It
tests run/collect/correct dispatch, stripped-role exact matches, missing and
malformed inputs, catalogs and symlinks, and two deterministic replacement
races. The baseline test uses only synthetic reserved bytes. A fake simulator
exits before any episode completes; no real simulator, policy or GPU is run.
Independent review reran all eleven CPU/socket groups, including the bounded
repeated-snapshot memory test and its deliberately leaky negative control.
The result is limited to this prototype and does not enable either gate.
