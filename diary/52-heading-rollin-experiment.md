# Matched heading-distribution roll-in experiment (staging)

The bounded runtime-bias pilot exercised 30 eligible actions but changed no
class, and control and treatment produced identical action sequences. Do not
expand it. The next hypothesis is to teach the same policy on corrective
labels visited from more than one initial heading, rather than perturbing
inference logits.

Both arms start from the same read-only epoch-8 treatment model and replace
exactly the same four old L5 student-driven correction shards in the existing
1,024-game mixed aggregate. Each arm obtains four new 32-game L5 shards from
that same model, same teacher, camera, scenes, seeds, start position and
layout/case order. Each shard has 30 fitting and two validation games. Control
uses yaw 0.42 throughout. Treatment uses 0.35, 0.42 and 0.49 radians, 40
fitting games each, crossed with the three training layouts (14/13/13 per
yaw). Its eight validation games use yaw 0.42, identical to control. The
exogenous difference is the fitting-start heading distribution; resulting
student trajectories, images and teacher labels will differ by design. Both
arms also replace old L5 roll-ins generated by an earlier model with new
roll-ins from the same newer parent. That shared substitution means neither
arm compared to the old parent alone isolates heading diversity.

Before either arm can train, audit each source shard's policy, seed, labels,
frames, scene and complete 300-action traces. For matching layout/seed pairs,
check actual initial pose and brick placement; validate that the only generated
scene-byte difference is the intended spawn yaw. The eight newly collected
validation games must have byte-identical images, feedback, teacher labels,
weights and maps across arms. The merged datasets must have the same 96
validation games byte-for-byte (including those eight) and the same remaining
896 games in identical fitting/validation positions with identical masks and
maps. If collection or aggregation is not deterministic enough to satisfy
those checks, stop; do not silently select different validation examples.
Check that the 40 shared-yaw fitting games also match across arms. Retain
records, partial files and data; the actor's carry cue still comes from
simulator task state rather than a physical sensor. Teacher labels use wall
geometry, not target coordinates, according to the existing teacher audit;
this is not a claim of physically supervised learning.

Both arms use the same training seed, eight epochs, batch two and identical
optimizer, mirror augmentation and carry-cue flags. Compare saved first/final
order, initial weights, first mirror mask and per-epoch optimizer counts.
Evaluate both fixed epoch-8 checkpoints; because both arms have identical
validation bytes, selected checkpoints can additionally be compared without
the changed-validation confound of experiment 35. Check L5 room entry,
first pickup and delivery, and L1/L3/L4 delivery and back-and-forth tradeoffs
on the existing factorial selection plus preselected new seeds on the same
training layouts. These are selection diagnostics, not held-out evidence.
No held-out reservation, data or disabled evaluator is accessed. The new
roll-in seeds are checked against recorded source-shard ranges, but no check
can prove all unrecorded historical uses or pretrained ancestry.

A separate four-game pilot collects two games per arm: one different-yaw
fitting example and one identical-yaw validation example. It must verify
reported start headings and matched placement, teacher-label disagreement,
source/model receipts, byte-identical validation data/maps and preservation
through the same map aggregation and teacher-only mask before full collection.
The pilot is independent of the full experiment and is never added to it.
After the roll-in pilot, a separate one-epoch training pilot uses its 34-game
aggregate, the same parent, seed and trainer to compare a stock control binary
with the isolated FICLONE-copy control. It must match initial and final
weights, gradients, first/final ordering, initial mirror mask and recorded
epoch metrics, and prove source physical mappings and clone sharing. A
mismatch is retained and stops full collection. After independent review and
with the GPU idle, the staged sequence is:

```
P=build/flex/sim/levels-v2/pitch82
python3 -I datasets/visual-control/chase-v1/levels/prepare-heading-rollin.py pilot "$P/heading-rollin-pilot-catalogs"
python3 -I datasets/visual-control/chase-v1/levels/supervise-heading-pilot.py
python3 -I datasets/visual-control/chase-v1/levels/prepare-heading-trainer.py
python3 -I datasets/visual-control/chase-v1/levels/run-heading-trainer-pilot.py
```
