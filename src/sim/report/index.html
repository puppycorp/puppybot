    HOW TO READ THIS REPORT

    Pixels in. Evidence out.

    01 / PERCEPTION

    A simple RGB detector

    Colour and shape components find bricks. This collection task does not use a trained Lego YOLO model. The box uses visible rim markers.

    02 / SUCCESS

    Six real placements

    A pass requires all six dynamic bricks released and settled inside the physical box. Simulator geometry checks the outcome independently.

    03 / REPLAY

    Keep the original run

    Every run retains its scene, sensor images and replay script. The inspector can copy the command for your original PuppyBot workspace.

    Experimental scope and provenance

    The two existing robot cameras keep their original mounts and field of view. The world view is an observer view. No third sensing camera was added.

    The robot uses ideal simulated odometry, a known flat floor and brick height, and an assisted contact-weld grasp. Scenery props are fixed cuboids. Lighting, image noise and wheel slip were not varied in this experiment.

    Green sensor boxes mark the selected component; yellow boxes are other components. These are offline overlays on the actual camera frame. A component fill ratio is not a learned confidence score.
